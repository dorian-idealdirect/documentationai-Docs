---
title: Project Not Showing Up
description: Fix missing project listings in Idealsync.
---

## Problem

- Project recently created but not visible in your dashboard.
- Unable to access a project shared with you.

## Solutions

<Steps>
  <Step title="Refresh the dashboard">
    Use your browser's refresh or reload button.
  </Step>
  <Step title="Check workspace selection">
    Make sure you have the correct workspace chosen from the sidebar.
  </Step>
  <Step title="Verify project permissions">
    Confirm you have access rights if the project is shared.
  </Step>
  <Step title="Contact support">
    If none of these steps help, email support@idealsync.com with details.
  </Step>
</Steps>
