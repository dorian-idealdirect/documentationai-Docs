## Upgrade Process

Follow these steps to ensure smooth updates. Most changes apply automatically, but verify custom configurations.

<Steps>
  <Step title="Check Current Version" icon="package">
    Run the version check command in your terminal.
    
````bash
idealsync --version
````

    Expected output: `v1.2.0`
  </Step>
  <Step title="Update CLI" icon="download">
    <Tabs>
      <Tab title="npm" icon="package">
````bash
npm update @idealsync/cli -g
````
      </Tab>
      <Tab title="yarn" icon="package">
````bash
yarn global upgrade @idealsync/cli
````
      </Tab>
    </Tabs>
  </Step>
  <Step title="Restart Workspace" icon="refresh-cw">
    Refresh your browser or restart the local server.
    
    ```
    idealsync dev --restart
    ```
  </Step>
</Steps>
